# Akash S — Interactive Portfolio & Experience Platform

A high-converting, developer portfolio designed to showcase software engineering, web technologies, and AI capabilities to recruiters and hiring managers.

Built with a focus on **speed**, **tactile interactivity**, and **tangible proof of work**.

---

## 🌟 Key Conversion Features

1. **First-Impression Hero & Live Status**:
   - Availability pill with live status: `Bangalore, India 📍 • Immediate Joiner / Open for Full-Time Roles`.
   - 1-Click "Copy Email" with tactile feedback and toast notifications.
   - Direct WhatsApp conversation button (`+91 90199 98288`).
   - Quick counters: 3+ Shipped Projects, 9+ Verified Certifications, 5 Spoken Languages.

2. **Interactive Developer CLI Terminal (`Ctrl+K`)**:
   - Recruiter-oriented terminal emulator with command history (`Up`/`Down` arrow navigation).
   - Commands: `about`, `skills`, `projects`, `experience`, `certifications`, `contact`, `resume`, `sudo hire akash`.
   - Running `sudo hire akash` triggers celebratory confetti and a direct offer confirmation modal!

3. **Interactive Project Demos (Proof of Work)**:
   - **Spice Garden**: Custom animated SVG Kerala Spice Wheel demo modal with rotational physics and spice aroma breakdowns.
   - **Track Titan**: Live fitness telemetry simulator demonstrating real-time state mutations, calorie calculations, and streak monitoring.
   - **Vogue Connect**: Creative industry networking platform architecture and database showcase.

4. **Web Audio API Sound Engine (SFX)**:
   - Synthesizes crisp micro-sounds (click pops, keystrokes, success chimes) without external audio file latency.
   - Easily muted/unmuted with top navigation toggle; persists user preference in `localStorage`.

5. **Print-Ready / PDF Resume**:
   - Includes `resume.html` styled for clean browser printing (`Ctrl+P` -> Save as PDF).

6. **Filterable Skills Matrix**:
   - Interactive filtering across Languages, Web & UX, Databases & Systems, and AI & Automation.
   - Click any skill pill to copy it to clipboard.

## 🚀 How to Run Locally

### Option A: Zero Installation (Direct in Browser)
Simply double-click `index.html` or open it with Google Chrome, Microsoft Edge, or any modern web browser.

### Option B: Using Python's Built-in Server
In this directory, run:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

### Option C: Using Vite (Node.js)
```bash
npm install
npm run dev
```

## 🌐 Deploy to the Web (Free in 2 Minutes)

### Deploy to GitHub Pages:
1. Push this folder to a GitHub repository named `portfolio` or `<your-username>.github.io`.
2. Go to repository **Settings** > **Pages**.
3. Under **Build and deployment**, select **Source: Deploy from a branch** and pick `main` (root `/`).
4. Click **Save**. Your site is live!

### Deploy to Vercel or Netlify:
- Drag and drop this folder directly into [Vercel](https://vercel.com) or [Netlify](https://netlify.com) dashboard for an instant worldwide HTTPS deployment.
